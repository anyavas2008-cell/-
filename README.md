# УрФУ-попутка

Сервис поиска попутчиков для студентов УрФУ (маршруты в кампусы и обратно, расчет расстояний по районам).

## Запуск

1. клонируй репозиторий и перейди в папку
2. создай `.env` на основе `.env.example`
3. запусти через докер:

```bash
docker compose up -d --build
```

## AI-ассистенты

* **инструменты:** Gemini, Claude
* **для чего:** помощь с написанием конфигурации Docker Compose, структурой README и логикой бота.
* **что проверено вручную:** контейнеры собраны локально, проверен рестарт через `docker compose down` и `up -d`, данные в базе сохраняются благодаря настроенным volumes.
